# Final Project — Infectious Cases

## Description
Analysis and normalization of infectious disease data using PostgreSQL. The project includes database design, SQL queries, date calculations, and custom SQL functions.

## Technologies
- Python
- PostgreSQL 16
- SQLAlchemy
- Pandas
- Google Colab

## Dataset
`infectious_cases.csv` — infectious disease statistics by country and year.

## Tasks Completed
- Imported CSV data into the `pandemic` schema.
- Normalized the dataset to Third Normal Form (3NF).
- Analyzed rabies statistics using aggregate functions.
- Calculated year differences using PostgreSQL date functions.
- Created and tested custom SQL functions for year differences and average disease cases.

## How to Run
1. Open `final_project.ipynb` in Google Colab.
2. Run the notebook cells sequentially.
3. Ensure the PostgreSQL environment and database connection are configured.
